# Software Testing and Quality Assurance
Software Testing and Quality Assurance projects using Java and JUnit 5

# How can I ensure that my code, program, or software is functional and secure?

To make sure my code works correctly, I review the requirements and test it using both valid and invalid information. In this course, I used JUnit 5 to test my Contact, Task, and Appointment services. I also checked my code coverage reports to see how much of my code was tested. Even when all my tests passed, I learned that it's still important to check for other issues, such as invalid information being accepted or problems that could affect security.

# How do I interpret user needs and incorporate them into a program?

I first look at what the user needs and what the program is expected to do. For example, in the Contact Service project, I had to make sure users could add, update, and delete contacts while following the requirements for names, phone numbers, and addresses. I used these requirements to write my code and decide what needed to be tested. This helped me keep track of what was required and make sure I wasn't missing anything.

# How do I approach designing software?

I usually start by going over the requirements and working on one part of the program at a time. For these projects, I worked on the classes and services before creating my JUnit tests. I had some trouble with the update and delete methods, so I had to go back, review my code, and figure out what was causing the problems. Working through those issues taught me to test my code as I go instead of waiting until the end. It's something I plan to keep doing in future projects.
